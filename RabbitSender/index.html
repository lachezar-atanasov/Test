RabbitSender API

POST /api/RabbitSender/Send
Send message to default queue
curl -X POST -H "Content-Type: application/json" \
     -d '"<trade><tradeId>123</tradeId></trade>"' \
     http://localhost/api/RabbitSender/Send
POST /api/RabbitSender/SendToQueue?queueName={queue}
Send message to specific queue
curl -X POST -H "Content-Type: application/json" \
     -d '"<trade><tradeId>123</tradeId></trade>"' \
     http://localhost/api/RabbitSender/SendToQueue?queueName=myqueue
